### 欧恩斯坦家族

相关短篇：《离别之战（安德烈与铎利克）》《血宴之夜》《北境来客（洛德与赫尔曼）》。故事线导读：欧恩斯坦家族线。

- 温德林·欧恩斯坦（Wendelin Ornstein）— 帝国初代皇帝，初代纯血龙裔，化龙为"猩红的温德林"
- 西格里克·欧恩斯坦（Sigric Ornstein）— 帝国第二代皇帝，温德林次子，"弑亲者"
- 安德烈·欧恩斯坦（Andre Ornstein）— 议会第二席，总帅，守护帝国两百余年
- 伊尔莎·欧恩斯坦（Ilse Ornstein）— 龙裔，崇尚暴力与战斗，莱瑟之母
- 艾德琳·欧恩斯坦（Edeline Ornstein）— 议会第三席，外交官，血宴总导演
- 洛德·欧恩斯坦（Lord Ornstein）— 议会第四席，白色守望副军团长
- 维克·欧恩斯坦（Vic Ornstein）— 议会第五席，纯血龙裔，魔导义体研发者
- 泽娜·欧恩斯坦（Zena Ornstein）— 议会第六席，龙血实验产物，图书馆管理员
- 铎利克·欧恩斯坦（Doric Ornstein）— 安德烈的学生，莫洛恩冒险者公会会长
