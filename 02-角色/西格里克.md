# 西格里克·欧恩斯坦

**西格里克·欧恩斯坦（Sigric Ornstein）**，帝国第二代皇帝。名字取"胜利 + 统治者"之意。

## 身份与谱系

温德林的次子。长女是老大，次子老二，三女老三。他是温德林与长女所生。

在龙裔中辈分属最高的一档。比他年长的只有长女，而长女是温德林与人类所生，血统纯度不高。西格里克与三女、安德烈的血统同属一档。

子嗣：

- 安德烈是西格里克与三女所生。
- 第三代皇帝也是西格里克之子，是真正的圣阳信徒。
- 皇位大概率由西格里克与三女的其他子嗣继承。从第三代起，皇位和军权由兄弟两支分开：一支世代承袭皇位，安德烈一支执掌军权，直到血宴。

## 性格与定位

杰出的政治家，不是战士。龙性中的掌控欲，他通过制度手段来实现，而不是靠暴力。

温德林是绝对权威，对他人漠不关心，尤其不管与自己规划无关的事。这份漠不关心对所有人一视同仁，并不是专门针对西格里克。西格里克则会拉拢人、许诺利益、给予尊重。龙裔倒向他，原因就这么简单。

他最擅长的不是剥夺别人的权力，而是把权力和尊严还给别人的同时，悄悄把自己的手伸进去。前面有温德林全部拿走，他还回大部分，只要求一部分介入，几乎没人反对。

他想做的是真正的皇帝，坐上温德林从来没真正坐过的那个位置。

维克认为龙化的成功率并不高，没有参与温德林的化龙，两人从这里产生分歧。维克转而支持了西格里克。

## 第一次内战与化龙

西格里克是第 0 期龙骑士团团长。

他知道父亲在做某件事，也想过可能是化龙，但无论如何都难以想象这种可能。温德林的强大是公认的，他不想让自己的班底在这场仗里折损，于是让龙裔不全力作战，把人保存了下来。

温德林化龙后，他与公爵们结成统一战线，联手杀死了巨龙。"弑亲者"这个称号由此而来。这只是他众多绰号中的一个，并不是概括性的称号。

## 在位

在位约八十年，大部分时间用在外交和各项制度雏形的落实上。

时间轴：温德林当皇帝不到三十年，第一次内战和化龙发生在 IE 三十几年；第三代皇帝在 IE 110 多年即位，此时帝国机制已经基本成型。

### 统合德拉科尼斯

他先完成了德拉科尼斯内部的统合，把统治方式从家族暴力转向"制度上的正确"。

官制借鉴雷加利亚。雷加利亚英雄分治、代际传承，因此需要稳定的行政体系兜底，保证即便领袖能力不足，整体也不会失能。

### 宫廷六职

- **首席大臣**：通常由梅特卢姆家族出任。
- **总帅**：先由他本人暂代，后交给安德烈。安德烈只接军权，不碰政务。
- **财务**：公爵叛乱让他认识到后勤的分量，这一职由此实质化。
- **司法**：更接近顾问职，成文法很少。
- **外交**：为市政厅铺路。温德林不管公爵之间的内战，西格里克会出面调停。
- **内务**：相当于他的私人管家。

### 议会

议会的本质是家族机关，不是国家机关。他是以欧恩斯坦家族的身份，而不是以皇帝的身份，把所有龙裔召回，确认他们的行为逻辑和方针。

他主持两套会议：宫廷会议讨论皇帝和帝国的利益，家族会议讨论龙裔群体的发展。

议会是皇权的延伸工具，让龙裔承担责任、听他指挥，而不是限制皇权。

### 血统政策

- 刻意保住高纯度一线（显性、稳定的那一档）不断。
- 龙裔与普通人生育，他一概不管，但这类后代无论如何都不冠欧恩斯坦姓。
- 伊尔莎那一档不在管理范围内，因为根本指望不上。

### 其他

- 四大家族的提名出自他手。第四家族目前挂起。
- 龙骑士继续由皇帝直属。
- 推动市政厅介入地方政治。

## 与圣阳教会

教会与帝国合流的第二阶段，发生在第一次内战后、他在位期间。第二次圣战榨干了教会，他趁机为教会输血，建立固定的医院礼堂和修士培训体制，并以制度化的方式推选出帝国认可的教宗。

教会内部的反圣战派倒向他，因为他至少表现得很尊重教会，由此出现两位教宗并立。罢黜前夕，他令安德烈杀死了威信系的战士教宗，对外宣称其"未能光复圣地，含恨而终"，教会并不知情。教会随后废除教宗制，帝国一方的教宗被降为首任德拉科尼斯大主教。

他为政治止血编出的殉道叙事，后来喂大了儿子（第三代皇帝）的圣战梦。

【待定】教会虽然拆掉了教宗这个阀门，但对资源的依赖本身就是他那只常驻的手。

详见 组织／圣阳教派。

## 三代皇帝

温德林造了壳，西格里克造了骨肉，第三代皇帝是第一个真正行使帝国权力的人，称号"征服者"。

征服北境归第三代，不归西格里克：不让一个人包办所有功业，同时也给继承人留下现成的功业。

## 待核

- 纪年：对话中定的是"IE 1 是帝国建立之年，发生在征服战争中途"；旧档《编年史》写的是"以征服战争结束翌年帝国建立为元年"，征服战争为 BIE 16 — BIE 1。【待定】
- 官职：旧档《政治与制度》的内阁有七职（首席、总帅、军务、财政、司法、外交、内务），比上面的六职多一个"军务"，瓦莱里安即任军务大臣（总帅的副手）；"财务"与"财政"的叫法也不同。【待定】
- 科莱帕齐亚复辟：皇帝为安抚遗民许诺了土地，发生在内战期间，许诺的是温德林还是西格里克，没有明确。【待定】
- 尚未设定：第三代皇帝的名字；西格里克其他子嗣的数量和名字；他的结局与死因；他与三女的关系细节；外貌。【待补充】
- 旧档需同步：《欧恩斯坦家族》"次子可能就是后来的皇帝"已坐实；《编年史》北境征服应归第三代；《编年史》《政治与制度》中议会为限权产物的说法已被取代；《编年史》第一次内战"~IE 10-15"作废，现为 IE 三十余年；《征服战争与帝国建立》中安德烈"无意也无力成为皇帝，最终以总帅的身份守护帝国——而非继承皇位"需改写；《第二次帝国内战（血宴）》中皇帝"不甘被议会架空"的动机需改写。
