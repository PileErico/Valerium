# 命名含义

## 巨龙

巨龙的名字随其相处的文明而来，语言即那个文明的语言。其中奥古斯都、海姆斯是帝国学者的命名，巨龙本身大多并不在乎名字；萨菲恩缇娅是她学习星语之后自取的。

| 名字 | 语言 | 原文 | 含义 |
| ---- | ---- | ---- | ---- |
| 奥古斯都 | 星语（拉丁语） | Augustus | 庄严的、崇高的 |
| 海姆斯 | 星语（拉丁语） | Hiems / Hyems | 冬 |
| 萨菲恩缇娅 | 星语（拉丁语） | Sapientia | 智慧（自取） |
| 庚辰 | 汉语 | — | 【待补充】帝国学者据煌武人口述记录 |
