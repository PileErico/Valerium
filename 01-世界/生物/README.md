# 生物

## 以太与生物演化

以太存在于宇宙、星球的时间甚至比生命还早。如同太阳向地表输出光和热，这个世界的卫星持续向星球输出以太粒子——一种更特殊的能量。所有生物都在以太的照拂下演化，就像现实中所有生物都在阳光下演化一样。

这个世界不存在现实意义上的"普通动物"。正如现实中有的生物高度依赖阳光（变温动物离了太阳就无法维持体温），有的生物对阳光几乎无所谓（深海生物），这个世界的生物对以太的依赖也是如此——程度各异，没有明确界限。

- 有些生物几乎不依赖以太，有没有都一样活，所以看起来和现实中的动物差不多
- 有些稍微利用了一点，但外在表现不明显
- 有些深度依赖以太，进化出了以太驱动的特殊器官和能力，一旦离开高能以太环境就会快速死亡——正如变温动物离开阳光就无法存活，依赖并不意味着强大

以太的高能性使这个世界的活跃度远超现实——文明更替更频繁，进化更快，但能走到最后的很少。因为基于以太这种特殊变数而成立的生物和文明都是脆弱的：没能拥有适配其能力的认知而导致自我毁灭并不稀罕。

对以太的利用是进化的一部分——是本能，是天赋能力，不是魔法。北地的冰巨魔体格强大，但它拥有的魔力大部分被作用于强大的肉体再生能力和保护自身的特殊器官——体内储存超低温液体的小囊可在必要时喷涂低温液体，液体瞬间闪蒸凝结为白雾，正常生物触碰即冻伤，吸入则因呼吸道坏死而直接死亡。这不是魔法，这是它的生态，是进化出来的能力。

人类恰好是演化过程中无数次分叉都避开了以太利用为主的变异，最终保持了不被以太深度塑造的纯粹。但人类不是唯一的这类情况，也有别的生物一路演变下来没有被以太显著改变。人类的独特之处在于知性足够高，由此发展出了主动利用以太的技术——即魔法。

## 怪物

**怪物**不是学术分类，是实用分类——拥有以太驱动的特殊能力、需要专业手段对付的生物。它们的生态极为鲜明突出，数量更少，因为其生理特性同时受到正常生态条件和以太条件的双重制约。

一般来说，会被冒险者选为讨伐目标的，都是因以太而进化出特殊能力的生物。

一些特殊怪物会被命名，以强化辨识度，便于悬赏、登记和研究，称为具名怪物——即拥有名字的特殊个体。行会与学院的命名是常见的途径，流程见冒险者条目。起名是为了把这些特殊个体与其他普通的同类区分开，不论研究还是讨伐都有必要。名字通常不会过于复杂和难以理解，要的就是让人直观理解其特征和性质。巨龙种全体都是标准的具名怪物。

## 龙类

龙是另一个层级的存在。

被称为"某龙种"的生物并不构成一个共同的类群，彼此没有共同的龙类祖先：兽龙属合弓纲，飞龙属蜥形纲中的主龙类，蛇龙属蜥形纲鳞龙类中的有鳞目，地龙与林德蠕龙属鳞龙类中的喙头目，羽龙则在蜥形纲中介于主龙类与鳞龙类之间、自成一支。它们被归为龙，是因为趋同演化带来的同一类龙化特征——**血液富含魔力**。血液能积蓄魔力，甚至能从亲代继承魔力，这是它们能够熬过以太升降的根本原因。

每一种龙都是从某个节点开始，拥有了足够突出的特化点，从而自成一派，并顽强地存续至今。例如兽龙的特化点在于极强的社会性、优越的适应力、更快的演化和迁徙。

爬行分类的龙类往往不会往寒冷的北方移动。

生物的巨大化也和以太周期有关。六七千万年前的爬行种时期是高魔力期：没有操控魔力所必须的智慧，就转而用魔力支撑强大的肉体，越长越庞大，互相厮杀。以太衰落之后，能不能继续支撑那具躯体，决定了谁活下来。少数巨型个体存活至今，例如利维坦。
