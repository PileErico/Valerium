# 巨龙（Dragon）

生物的顶端。四足双翼，出色的智慧和力量，能沟通甚至使用魔法，根据区域演化出不同习性，数量极少，独居。

始源龙：【待定】

## 归类的性质

"巨龙种"这个概念本身是帝国学者提出的归类，判据只有一条：**四足双翼，拥有智慧**。抛开这一点，每一头巨龙实际上各是独立的品类——一龙一种。品种与归类分层，煌武与帝国各按自己的认知立名（如庚辰的品种"应龙"即是煌武的认知）。

## 已知的巨龙

| 名号 | 品种 | 概况 |
| ---- | ---- | ---- |
| **黄金的奥古斯都** | 金龙 | 已知最强大的肉体力量，完全不使用法术。居于至高峰，年迈，甚少外出 |
| **永冬的海姆斯** | — | 北境巨龙，被巫妖安德里亚斯杀死并转化为亡灵龙 |
| **天命的庚辰** | 应龙 | 煌武的图腾与契约圣兽，受供奉得位格。现陷入长眠 |
| **全知的萨菲恩缇娅** | 慧灵龙 | 暂留帝国图书馆。专注法术，跟人类学会了理术，能重构自身形态变为人形 |
| **猩红的温德林** | —（龙裔化龙） | 诞生数周后被杀死 |
| **星龙** | 【名字待定】 | 星外来客，纯以太飞行。受困于此，最后目击于星民时代 |
