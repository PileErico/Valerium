# 煌武 · 七星城

> 一座以人力撼天地的百年国家工程。规划循北斗七星之名与序、逐运营建，建至第六城后搁置第七，实存六城。煌武三大奇观——永安渠、长垣、钧天九重圜丘——皆出于此。

---

## 一、缘起

庚辰长眠后，煌武失去那支倚仗千年的外部抑制力，境内乱作一团。一位德才兼备者于乱世中以个人魅力与政治手段挺身而出，征服拉拢割据诸侯、重归一统，自领帝位。七星城正是他的远见：**不再依赖巨龙之力，要以人力撼动天地——不论付出什么代价、需要多少时间、死去多少人。**

工程的精神内核与煌武「事在人为」一脉相承：与天地灾患相争是目的，顺水性、顺地势疏导是手段，二者并不矛盾。它既是治水安邦的实利工程，也是「无龙时代」一座纯人力的丰碑；衍州水患的改善，正是民心信任的实时回报。

## 二、命名与营建法则

**借北斗之名与序，非星图几何。** 七城取北斗七星之名（天枢、天璇、天玑、天权、玉衡、开阳、摇光）为命名与建造次第，第 N 座即第 N 星。但城址由地势水文决定，顺势而非凑形——动一地的风水气运，目的是与天地争，手段却必须顺地势而行，故选址只锚在真正的地理咽喉上，不为复刻星图而强选。

**三元九运，逐运营建。** 一城应一运一星，卡在它那颗星当令的二十年里动工，**星当令则城兴、工程得天时**。七运各二十年，合约一百四十年。煌武无力同时兴建，逐座完成；永安渠仅主干与东西渠便耗五十余年，天镜湖等仍待后续，整盘呈开放式扩展。

**斗魁主内政，斗柄主武。** 前四星（天枢、天璇、天玑、天权）为斗魁，立政治、粮储、财货、文教之根基，落核心开发区；后三星（玉衡、开阳、摇光）为斗柄，铺「武定四方」的守、告天、攻三面。建造由魁及柄，即由养民之基推向武功之极。

### 一·天枢（一运 / 一白贪狼 / 水 / 大吉）

国都，永安渠分流口所在。天枢星象征皇权，风水属水、大吉——皇权之城坐镇中枢，中枢锚于水系命脉，水属又大吉，配得起开篇第一座。永安渠为其核心工程：分永安西渠（引水入天镜、蓄水）与永安东渠（抵沧阳、汇入沧河），既连京畿与南方的水运动脉，又分泱水于衍州的过量水以缓水患、调水济西南。

科考上，天枢主中央二场之一：殿试由天子亲策、放榜在京（详见天权）。

### 二·天璇（二运 / 二黑巨门 / 土 / 当令吉）

衍州的仓储重镇，屯田建仓、积谷之所。二黑在峦头派为吉星，主田宅、财富、家业稳固；在玄空理气派吉凶随运，二运当令为旺。三义皆落于此城：

- **土克水**：衍州本是泱水诸汊汇集的水患地。天枢以永安渠先疏（分流入天镜），天璇再以土性镇压、压住水脉余动、防患复生——一疏一镇，先泄后压。
- **屯粮**：坤土主稼穑、承载、积累，治平后的衍州正宜屯田建仓。
- **军事根基**：仓廪实，方撑得起日后西北（垠州敞口方向）的军事与出击。先有衍州之仓，才有西北之兵。

### 三·天玑（三运 / 三碧禄存 / 木 / 当令旺）

沧州、沧河出海口的港湾，财货流通的支点。禄存之「禄」主财货，木主流通，三运当令则其凶性压下、吉性当头。沧河浩荡入海，**水生木**，正生旺这颗木星；港口靠水路而活，五行与功能双咬。

**璇玑为轴。** 天璇（衍州、仓储）与天玑（沧州、港口）合为「璇玑」一轴：衍州的粮货，经泱水渠系下浦州转海运、或走陉州的南北陆隘，汇于天玑港，再从此支点辐射天下、流通生财。一藏一发、一静一动，轴即转起——财聚于土仓、流于木港，周流不息。（陉州不入七星城，其南北咽喉的地理本分，正是这条陆轴。）

### 四·天权（四运 / 四绿文曲 / 木 / 文昌吉）

泱州天镜湖畔的最高学府，统秘书监（典籍档案）、翰林院（储才、文翰），尽收天下文人、书籍、学问。一座新城，小而清雅——不为活络人口，只为邀天下文人雅士齐聚、共思辨、共探讨。「煌照天下、武定四方」之外，此城立的是「绝不轻文、精神与物质并进」一极。

- **一四同宫主科名**：天权四绿落于天枢一白所在的泱州，构成玄空「一四同宫」的文昌顶格，文运科甲连绵；天镜湖之水（永安西渠自天枢引来）生天权之木，使「一白水生四绿木」的气脉相连，文昌格更实。整个泱州因此成为文昌之州，一州双城、文政相济。
- **科考三级**：地方乡试先筛，精英入中央；中央分两场，两颗文昌各主一场——天权（文曲、治学）考学问，天枢（贪狼魁星、天子）钦定放榜。天权那场到的本是层层筛过的少数，小城清雅不破。
- 煌武人口一亿出头，又是尚武之国，战士远多过书生，科考人流本就稀。唯其如此，文更易被武淹没，才更须立一座国家级的城把思辨高高托起。
- 【题解】煌武的道与德本无经文、无戒律，德随境而变，只能靠对具体情境的体悟、靠开放辩论去逼近——崇直尚言即此根。故天权不止是学府，更是煌武求道、修德、养共识的精神发动机。

### 五·玉衡（五运 / 五黄廉贞 / 土 / 正关煞最凶）

朔州的长垣边塞——煌武三大奇观之一。长垣非一道孤墙，而是将山隘相连、内外一体，集军工、冶炼、城防、操练、监管于一身的巨型边境要塞，横贯北境、卡北方山脉隘口。

- 五黄之凶配边关杀伐之险；土配土石长墙；廉贞主囚、刑，配其监管与军法。
- 「衡」即秤杆、横亘，正应长垣横贯北境。
- 五黄居中、至尊——长垣判内外、连内外，是华夷之间那条中界，又是镇国之重器，故以「居中之中界、至尊之重器」承其位。
- 五运五黄当令，倾国之力筑此凶险重器，正当其势。

### 六·开阳（六运 / 六白武曲 / 金 / 武贵吉）

嵚州天山段的钧天九重圜丘——煌武三大奇观之一，煌主祭天之所、最高等级的礼仪建筑。

- 祭天本是武功之礼：登基昭告天命、出师告庙、凯旋献捷——皆「武定四方」的告天大典。故这座坛由武曲（军权、武贵、征伐）来扛，名实相符。圜丘正是武定之后向天昭告、确立天命的最高礼仪。
- 庚辰长眠后，煌主失去巨龙的天命背书；圜丘祭天以「受命于天」的大典重立天命，正接「无龙时代」的精神。
- 次序上，玉衡（长垣、五运、先筑武备之墙）→ 开阳（圜丘、六运、再告天立命）：武备在前、告天在后，武定而后告天。

### 七·摇光（七运 / 七赤破军 / 金 / 凶）——搁置·未建

原规划为前线的进攻支点：破军主突击、征伐，与长垣（守的盾、墙线）相对，是攻的矛。【推断·待确认】其落点最宜在西北那个无山的敞口——煌武唯一的对外门户兼软肋；长垣守正北山墙、摇光据西北敞口，北境两段相补。

但六星之后，煌武对攻击他国已无兴趣。进攻支点是「能攻之力」，不等于「要侵之心」；耗举国之力筑一把不打算挥的矛，违了煌武的实用主义。于是第七城**搁置不建**，七星工程止于六城。

> 名唤「七星」，实存其六，缺的恰是斗柄末梢那颗破军、那颗「征伐」之星。煌武的北斗永远少一芒攻伐——这空缺本身，便是它守成、收锋、不贪的碑。【题解：整理者引申，待作者核定】

## 四、三大奇观皆出七星

煌武三大奇观尽出此一工程，且皆在已建的前六城之内、全部建成：

- **永安渠**（天枢·一运）：南北水运动脉兼水利枢纽。
- **长垣**（玉衡·五运）：横贯北境的巨型边境要塞。
- **钧天九重圜丘**（开阳·六运）：煌主祭天、确立天命之所。

## 五、时间线锚点

- 庚辰长眠 → 煌武内乱 → 新皇帝以个人魅力、政治手段平乱一统、自领帝位 → 启动七星工程。
- 第一城天枢＋永安渠：仅主干与东西渠便耗五十余年，天镜湖等仍待后续。
- 帝国第二次内乱（贵族战争）之时，煌武正建第三城天玑（沧河出海口）。
- 建至第六城开阳（圜丘）后，第七城摇光搁置，工程止于六城。

## 六、整体性格

煌武是一个**竞争能量内循环的守成型大国，而非扩张帝国**。

- **武是用来「定」的，不是用来「征」的**：武力极强（民间尚武、长垣边塞、七星武备），战略却守土不侵。三面以天山、北墙、东海为屏，易守难攻，守住屏障内这片辽阔疆土即足，无需向外征服。
- **能量向内释放**：与帝国封建制「扩张创造新封地、新贵族」的结构性外扩相反，煌武地已够大，竞争能量尽数向内消化——权力争夺（争煌主、明礼暗诡的政治博弈）、学术辩论（百家思辨，亦即认识道的方式）、武林大会（尚武之劲在此较量争雄）。政、文、武三股竞争能量全向内泄，对外自然无扩张之欲。帝国向外、煌武向内，两台发动机朝相反方向转。
- 七星工程止于六城、缺一颗攻星，正是这守成性格立在大地上的碑。
