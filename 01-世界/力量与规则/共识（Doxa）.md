# 共识（Doxa）

## 概念

**共识**是这个世界的一条底层规则——所有知性生物的认知拥有向下覆写物质层的力量。当一份被持有的认识强度足够时，这份认识会反过来作用于物质层，使被认识的事物以认识者所认识的方式真实地存在、运作或发生。

共识本身不是一种存在的实体，**它是一条规律**。一切超出寻常物质规律的现象——奇迹、神格、信念塑造现实——皆建立在它之上。

覆写需要**差**。认知与物质层实情之间的差是唯一的作用量——贴合事实的认知是纯粹的知识，无事发生。而对由共识立起的持续现象，贴合的认知恰恰就是供养：这类事物的存在本身由认知构成。

## 与真知（Episteme）的关系

[真知（Episteme）](真知（Episteme）.md) 是物质层的客观规律，独立于任何观察者而存在。严格地说，共识是真知的一部分，不与真知并列——"认知能覆写物质层"这条规律本身也是客观规律。以太、生物演化、物质性质这些是真知直接揭示的领域；奇迹、神格、信念塑造现实是共识的运作。

但两者之间存在一层张力。共识作为机制本身是客观规律，被真知所包含、所解析。然而共识具有连事物本质都覆写的力量——真知所认识到的"真实"，是否已被共识改写过？而"共识能覆写本质"这一规律本身，又确实是真知所能理解的。这层循环张力是这个世界最深处的认识论结构。

## 参与的门槛

参与共识机制需要**知性**——判据是**主动肯定一个东西的能力**。任何知性生物都参与，没有"知性而不参与"这种情况。

知性不等同于智力高低，也不等同于种族分类。[鬣狗人](../02-种族/鬣狗人.md) 的认知粗浅到只是基于本能的原始渴望，但已经跨过了阈值——憎恨与饥渴熔铸成明确的认知倾向，纯净的确信扭曲了事实。[The Hunger](../05-信仰/其他信仰.md) 是帝国学者为这份本能饥渴取的学术命名，不是鬣狗人的信仰。反之，[古龙](../03-生物/古龙种.md) 凭借强大的躯体与本能就能生存，从未演化出参与共识所需的认知能力——[库库尔坎](../03-生物/羽龙种.md) 作为始源古龙正属此例，它的神格与知性都是人类信仰赋予，不是龙自己产出的。

**参与共识**与**受映像作用**是两回事。前者要求知性，是为共识场提供信念的资格；后者不要求任何前提条件——映像在物质层兑现，对象的认知状态不进入判定。一头野兽不持有圣阳信仰，但圣阳修士的奇迹照样可以治愈它的伤口。

## 信念（Pistis）

**信念**是覆写的输入——知性生物持有的具体认知。强度足够的信念就是覆写物质层的力量——众人共持是最常见的来源，不是唯一的来源。

对神明的信仰、对道的体认、煌武人对"点穴可以封气"的共识——这些都是不同形态的信念。

### 三态：信念、认知、无输入

认知对共识的输入只有三种状态。

**信念**是确定的认知，形态只有一种：**肯定 X**。"X" 可以是某件事发生，也可以是某件事不发生——持有"圣阳存在"是肯定方向的信念（+1），持有"圣阳虚妄"是反向肯定（−1），仍是信念。唯有信念向共识注入力量。削弱一份共识不能靠"让人不再想它"——那是空操作；只能靠让人**反向肯定**这件事不真。

**认知**是仅仅知道。它不注入一分力量，但维系概念的存在。"知道关于 X 的事"不等于"持有 X"——帝国学者人人知道星民曾信仰星神，星神依旧不能复活：大伙只是知道，没人信这一套。

**无输入**是本能与悬置。本能不肯定任何东西——鹿的恐惧没有内容；纯粹暴怒中失控的人，在那一刻同样不具备认知。

由此有**两种死**。力量死：信徒死绝——概念仍被知晓，却再无一分力量可用。概念死：不再被任何人认知，事物随之不复存在。存在是当下认知的读数——蛇人长眠，他们的神不复存在；蛇人苏醒，神再度被认知、再度存在，同一性由头脑中原封不动的概念内容担保，无需任何东西熬过中间的空白。

### 信念是无法撒谎的

信念不是认知者对自己想法的口头报告，而是他整个认知-反应系统所体现的实际图景。情绪、行为、应激反应都是信念的一部分。

一个人嘴上说"我不信他会变成龙"，但他的恐惧、他的逃跑冲动、他的应激姿态——他的整套反应系统已经在按"他正在变龙"这个图景运作。共识看到的就是这个实际运作的图景。**身体不会为不相信的事流冷汗。**

口头可以撒谎，整套反应不能。这条判据只单向使用：反应系统暴露认知者实际持有的图景，反应本身并不构成认知——野兽的恐惧里没有图景可读。

### 信念的四个维度

信念能否兑现成映像，取决于它的强度——强度不够，就到不了映像那一步。一份具体信念的强度由以下四条维度决定。

**规模**：多少人持有这份信念。规模越大越强；无人认知则无任何信念存在。

**持续**：信念维持了多长时间。即便强度较弱的认知，长期存在的情况下也可能引发映像。

**同步**：持有者之间对信念内容的认知是否一致。从 -1 到 1 的连续谱——所有持有者完全一致为 1；互不相关、各持各的为 0；完全冲突的反向肯定为 -1。同方向规模再大，若 -1 的反向肯定足够，也会被抵消。

**精确**：信念的内容是否具体明确。越精确的认知越容易兑现——"绝对刚体"比"无坚不摧之物"更容易兑现，因为前者是清晰的概念，后者概念模糊。精确度同时决定兑现物的形态与时间结构：内容明确而确定，出雷霆——鬣狗人的"我要咬下你的头颅"，即时而具体；内容模糊而确定，出命运——道的"逆天者终将付出代价"，迟缓、弥散、必然。

强度的判定是**阈值制**：不及所求图景的门槛，就什么都不发生，没有打折兑现的版本。"断腿只止血消肿"是一张没有被任何人持有的图景，无从实现——候选结果永远只有两个：被持有的图景本身，或无。梯度存在于所求内容的选择上（求一张更小的图景），不在输出上。

### 主动信念与被动信念

信念按持有方式分两种。

**主动信念**：当下指向某件事发生的确定认知——"此刻 X 将发生"。修士施奇迹时指向"伤口愈合"，笃定而非祈求；信徒祈祷时指向"神会回应我"。主动信念是认知而非愿望——渴望其真不等于认知其真，再衷心的祝愿也不构成输入。

**被动信念**：作为对世界的认识本身持续在场的认知——"我对这件事的认知就是这样"。煌武人对道的认知、帝国市民对圣阳的认知——这些是被动持守的世界图景。

被动信念不需要持有者欢迎它、赞同它。只要他在认知里没法否定它，他就在持有它。即便心里不信，认知也已被加载——一个煌武境内的帝国人，在郎中和他谈论穴位经脉的过程中，"煌武人有经脉穴位"就已进入他的认知。这份加载供给的是观察者的养分：维系这套体系作为概念的存在，不注入兑现之力。

### 主动—被动的转化

任何事物从无到有进入共识层，需要主动信念的集中支撑。神明初创期靠大量人集中而确定的主动信念；新概念诞生靠少数人主动倡导。

事物一旦进入共识层并被广泛认知，就转入被动支持运作。维持它存在的不再是有人渴望它存在，而是有人**知道它存在**。

这是一道单向门：**主动认知让对象出现，对象一旦出现就成为真知**——之后再认识它的人，仅仅"认识"本身就在巩固它的存在。一个出生在已有圣阳信仰的世界里的孩子，不需要"主动确信圣阳存在"——圣阳对他而言是世界本来就有的一部分，他只是认识到这件事，而这份认识本身就在为圣阳的存在投票。

成熟期的共识系统通常**两层都在运转**：被动认知场作为基底，主动调用作为局部激活——修士施奇迹的瞬间、信徒祈祷的瞬间。

这条单向门也解释了为什么从无到有的成本远高于维持的成本。从无到有需要主动信念把一份新的认知从无中拉出来；已立的存在只需要被动认知就能维持。所有成熟信仰、所有久立的概念都站在门的另一侧。

### 概念摘出

信念指向的概念可以是既有的（伤口、愈合、火焰、武器），也可以是新创造的——后者要求把这份新概念**摘出**：为它命名、塑形、确立内容，让它可以被传达、认知、表述、理解。

把"羽蛇神"的权能兑现到库库尔坎身上之前，必须先有"羽蛇神"作为一份明确的概念存在——它是谁、长什么样、有什么权能。这份概念以那条古龙为原型，在漫长的供奉中被塑造、被添加，先立了起来，权能才有处可落。"道"作为一条因果律在煌武境内运作之前，必须先有"道"作为一份哲学概念被提炼、被论述、被传承。把武器变形为多功能变形工具之前，"多功能变形工具"这份概念本身得先在认知空间里立起来。

概念摘出本身不直接产出物质层效果——摘出的是一个共识层的锚点。但有了这个锚点之后，信念才能集中地指向它，共识兑现才能围绕它发生。

摘出和操作类型独立——指向新概念时需要摘出，无论这次共识兑现做的是扩增、变化还是缩减。绝大多数日常共识现象都指向既有概念（治愈伤口、强化武器、消除痛苦），不需要摘出工作；摘出主要发生在新事物被引入共识时。

## 映像（Eikasia）

**映像**是覆写的输出——信念投射到物质层后产生的实际效果。

修士施展的奇迹、淬阳武器获得的祝圣属性、煌武境内"道"作为因果律的运作、库库尔坎被信仰兑现成有知性的神、塞纳诺斯作为森林意志的在场——这些都是不同形态的映像。

### 三种操作类型

任何映像都属于以下三种操作之一。

**扩增（创造）**

让本不存在的东西出现。

- 在概念层兑现一份无实体的存在（如圣阳）——无肉身、无位置，却真实立在世上的概念性实在
- 实例化一条规律（如道），使其作为因果律在物质层运作
- 在已有载体上兑现一份概念（如库库尔坎——人类对它的"神明"信仰被兑现到这条古龙身上，知性、神格等"神明"应有的属性随之落在它身上）

扩增的门槛最高。目标在认知空间里发散度最大且没有起点——"创造一位神"里"神是什么样、长什么样、有什么权能"每个认知者都得在共识里为它填进具体内容，分歧空间最大；而且要从无到有，没有任何已有基础作锚点。

扩增造得出认知者——为载体安装知性——但**认知不能扭曲其他认知者的认知**：被造出的心智是它自己的。信徒的信念给得了库库尔坎知性与神格，指挥不了它的意志；献祭与恳求皆可，回应与否只看它自己。不存在脑控。

**变化（改变）**

让 a 变成 b。

- 修士治愈让伤口从损害变为完好
- 淬阳祝圣让武器从普通变为强化
- 庚辰从普通应龙变为被加持的契约神兽

变化的门槛中等。目标 b 的可能空间比"无"广阔，但有 a 作为起点提供锚点。

变化内部还有一道梯度——新增的内容越脱离原本质越难，因为无限接近创造。**强化原生属性**容易：物品本就有真实可见的属性，共识让这份属性被放大或固化。**凭空新造属性**极难：共识要从零开始让对象获得它本不具备的属性，缺乏真实锚点，怀疑容易产生。

**缩减（移除）**

把附加在载体上的非本然内容去掉，让对象回到没有这层附加的状态。

- 驱散诅咒
- 解毒
- 消除痛苦、平息情绪、抹除记忆

缩减的门槛最低。所有缩减型映像的目标都收束到同一处："无"。同步天然趋近 1——所有缩减认知都指向"让它消失"，没有"消失成什么样"的分歧空间。精确天然达成——"无"本身没有多种版本，疼痛消失就是疼痛消失。

缩减作为操作通常不留痕——一次性事件做完就没了，不形成"作为持续现象留在世界里"的样态。

## 描述维度

信念与映像是同一份共识现象的两面——信念是输入侧、映像是输出侧，但它们刻画的是同一件事。任何一份共识现象都可以沿以下四条维度刻画。维度之间彼此独立，每条独立取值；这套刻画工具不构成分类——同一份现象可以在四条上呈现各种组合。

### 操作类型

扩增 / 变化 / 缩减——具体见 [映像（Eikasia）—— 三种操作类型](#三种操作类型)。

### 持续 / 瞬间

兑现是否在物质层留存为持续状态。

- 持续：兑现作为状态长期在场——圣阳作为概念性实在的持续存在、道作为因果律在煌武境内的持续运作、塞纳诺斯作为森林意志的持续在场
- 瞬间：一次性兑现完成后退场——修士某次治愈奇迹、淬阳祝圣的过程

持续型现象里效果即结果——效果不结束，所以两者一致。瞬间型现象里效果是过程，结果是过程结束后留下的物质层状态——治疗过程是效果，愈合后的身体是结果。瞬间型现象的结果由物质层按自身规律继续维持，不再依赖共识。

### 有实体 / 无实体

被认知的概念是否对应一个物质层的先在载体。

- 有实体：庚辰（应龙）、淬阳武器（铁器）、库库尔坎（古龙）、塞纳诺斯（森林）
- 无实体：道（规律本身）、国运、圣阳（共识在概念层兑现的实在，无物质载体）

任何被认知的事物必有概念上的指向，否则构不成信念。区别只在概念有没有先在物质载体——有实体的映像是在已有载体上做强化或改造；无实体的映像是从无中在概念层兑现新的存在。

### 主动 / 被动

支撑这份现象的信念是主动指向的，还是作为对世界的认识被动持有的——具体见 [信念（Pistis）—— 主动信念与被动信念](#主动信念与被动信念)。

### 完整刻画

刻画一份具体的共识现象，沿这四条维度同时取值即可。例如：

- **某次修士治愈**：变化、瞬间、有实体（被治愈者）、主动
- **圣阳的持续存在**：扩增、持续、无实体、混合（多数信徒被动 + 修士与祈祷者主动）
- **庚辰**：变化、持续、有实体（应龙）、被动（煌武人对庚辰的认知是被动持有）
